#先前假設物理事實
1tmux send-keys rc=0 = 注入成功rc=0 只代表 tmux 收下按鍵。v1.1 成功條件改為畫面指紋改變，否則 rc=3
2DELAY_BEFORE_ACTION / debug_log 能修好 TUI 競態固定 sleep 不是握手。改為 fingerprint idle（ready）與 fingerprint change（send confirm）
3稽核軌 before 空白 = 當時沒畫面capture-pane 末行常是空行。改取最後非空行。07:46 before 空；18:41 before = drew@70 ~ %
4read 輸出正常printf '%s\\n' 在 bash printf 印出字面 \n。已改 '%s\\n' → 真實換行
5interactive 是 observe-act-verify舊實作固定 15×3s=45s 且從不因穩定提前結束。現為指紋穩定 2 輪即結束（實測 2s）
6空 send 無害空字串 + Enter = 對 TUI 盲送提交。現拒絕，rc=1
7兩顆具名 session 內嵌 Claude Codescan 顯示兩者 command=zsh alt=0。Claude 在 Terminal.app tty，tmux 無法注入
8中文 echo 字串可直接 $target（…）bash 3.2 + UTF-8 locale 把全形括號首 byte 吃進變數名 → unbound variable。改 ${target}
